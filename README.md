# Paradise Nursery

Paradise Nursery is a React and Redux Toolkit shopping cart application for an online houseplant shop.

## Features
- Landing page with a nursery introduction and Get Started button
- About Us page
- Houseplants grouped into categories
- Product thumbnails, names, and prices
- Add to Cart buttons that disable after a product is added
- Dynamic cart item count in the navigation bar
- Shopping cart with quantity controls, delete buttons, line totals, and cart total
- Continue Shopping button
- Redux Toolkit slice for cart state

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- CSS

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
